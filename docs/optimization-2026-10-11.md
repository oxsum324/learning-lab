## 必要調整與資料邊界

1. **錯因卡不直接改寫已提交紀錄的 mistake。** 派工原文要求直接寫入該欄，但現有雲端把相同作答 ID 視為不可變原稿；直接修改會在還原舊版本時造成內容衝突。因此另以作答 ID 保存 `{mistake, updatedAt}` 補充註記，歷史頁及 Markdown 同時呈現原稿與補充。已驗證原始紀錄逐字相同。
2. 補充註記、重練日期、使用回饋置於 JSON 的 `localPracticeNotes`。匯入先分離本機資料，再走原本學習紀錄合併流程；雲端備份仍取原本 state。**這些新欄位需以 JSON 搬移到另一裝置，尚未加入雲端同步。** 畫面已明示。
3. 分區檢視沿用先前「同頁連續作答」要求，不建立多張互不相連的圖紙。
4. 參考區是學習流程門檻，不是安全鎖；靜態網站題庫仍可透過開發工具讀取。每次開完整答案都如實記為等級 3，提交後的核對不污染新的空白草稿。
5. 無題庫、課表 JSON、後端、雲端設定或材料力學新增。雲端前端檔只由版本工具換更新快取鍵。
