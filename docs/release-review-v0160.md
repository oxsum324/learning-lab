## 審查及實際修正

三個分身分別審查結構／RC、鋼構／動力、土壤／保存。合計150課750組皆用獨立公式或力學不變量核對；另有150組反算回代。梁位移用虛功數值積分，RC用壓力塊合力與應變相容，鋼構／動力用虛功、合力力矩、特徵方程及積分關係；土壤另核對量綱、有效應力、排水與反算區間。此為教材與程式複核，並非外部技師逐題簽證、規範完整設計或官方原卷完整詳解。

## 使用者最後實測

新版入口：`/learning-lab/studio/index.html?v=0.16.0`。正式作答使用無sandbox的網址；純介面測試可加 `&sandbox=1`，該空間不連接私人Drive。

1. 先匯出既有完整JSON，再切換五科，各選一課及反算／改條件重練。
2. 先填一個首答，再看錯因提示、訂正、圖解並提交；歷史應同時顯示首答與提交值。
3. 切換題組及重新整理後檢查草稿、圖解及協助紀錄。
4. 若要驗證真實私人Drive，使用正式紀錄入口連接Google，手動備份未提交草稿；在另一裝置讀取、下載完整JSON並還原。雲端「合併作答」只合併提交歷史，保留本機草稿。
5. 回報科目、課次、題組及裝置；完整JSON含私人紀錄，勿放公開GitHub。實體iPhone／平板及真實Drive的完成與否，以其實際結果另驗收。
