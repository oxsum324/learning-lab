# 私人雲端往返驗證

驗證入口為 `verification/?run=批次編號`。兩個環境使用同一個 6～36 字元英數或連字號批次編號，並連接既有 Google 帳戶。

1. A 環境執行「寫入兩版」，涵蓋五科的舊版作答、新版多選／排序／數值首答、提示、草稿與非空圖解。
2. B 環境執行「還原並回存」，逐欄核對全部內容，檢查重複匯入、歷史衝突、草稿衝突及合併保留目的端草稿，然後新增第三版。
3. A 環境「回讀第三版」，確認雙向傳遞及前兩個版本仍可讀取。
4. B 下載已讀回的第二版，在學習平台 `sandbox=1` 功能測試空間匯入，檢視圖解與歷史，匯出後交回驗證頁比對。
5. 兩端下載收據；比較正式歷史唯讀核對的檔案編號及 SHA-256，確認隔離測試期間正式歷史未變更。

## 隔離與權限

- 驗證請求帶固定 `space=verification`，後端使用另一個 appProperties 分類及「Learning Lab 私人雲端驗證」根目錄資料夾。
- 未帶此參數仍使用原來的私人學習歷史。無效或重複參數拒絕；跨空間直接讀取檔案也拒絕。
- 前端必須先確認後端支援隔離空間，否則停止，避免舊後端忽略參數後誤寫正式歷史。
- 既有帳戶、來源、Drive 權限、私人分享檢查及大小限制不變。沒有新增 OAuth 範圍或第三方收件者。
- 驗證頁只在記憶體保留權杖，收據不含權杖或作答正文；不修改平台正式 localStorage。
- 模擬資料皆標示驗證用途，不是使用者的學習成績。不得匯入正式學習空間。

## 驗收邊界

兩個獨立瀏覽器可驗證儲存、授權隔離及真實雲端往返；實體手機／平板仍須在該裝置開啟驗證入口執行 B，另查觸控、下載與匯入行為。完整 JSON 匯入可帶回草稿，雲端「合併作答」只加入歷史並保留目的端草稿。

收據區分本機模擬測試、真實 Drive 往返、平台圖解呈現及實體裝置測試，不以其中一項代替其他項目。
