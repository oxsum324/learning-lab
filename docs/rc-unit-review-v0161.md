| 來源量 | 顯示換算 | 範例 |
|---|---|---|
| 力 | 1 tf＝9.80665 kN | 1000 kN＝101.9716213 tf |
| 應力 | 1 kgf/cm²＝0.0980665 MPa | 28 MPa＝285.5205396 kgf/cm² |
| 鋼筋強度 | 同應力精確換算 | 420 MPa＝4282.8080945 kgf/cm² |
| 彈性模數 | 同應力精確換算 | 200000 MPa＝2039432.42596 kgf/cm² |
| 面荷重或地基壓力 | 1 tf/m²＝9.80665 kPa | 100 kPa＝10.19716213 tf/m² |
| 剪流 | 1 kgf/cm＝0.980665 N/mm | 應力、剪流不可互當相同單位 |

不可將 28 直接改寫為 280，亦不可將 420 直接改寫為 4200；這會改變題目的物理強度。顯示可以合理取位，核對值與計算仍保存完整精度。

## 實作邊界

- 原數值解題函式繼續以 SI 核算。RC 專用單位邊界在題給、答案、反算、輸入及詳解處轉換。鋼構、土壤等其他科不受 RC 顯示偏好影響。
- 新 RC 模型的公開參數及答案均使用重力單位；求解入口先還原 SI、出口再轉顯示。共用容量剪力模型另立 RC 版本，避免動力課被連帶改單位。
- 舊課表來源檔與既有題庫記錄保留 SI，經 `rcLegacyCourse`／`rcLegacyDay` 產生顯示副本。此處須不改來源、重複套用亦不再換算一次。
- 使用者舊作答、首次答案、已提交快照及歷史詳解不套新單位換算。舊題稿與新題面須有內容版本提示，不能默默重新評分。

## 易錯公式

1. 以 As（mm²）、fy（kgf/cm²）、d 與 a（mm）求 Mn（tf·m）：`Mn=As·fy·(d−a/2)/10^8`。同單位的 fy/fc 相除求 a 時比例不變，但內力乘面積仍需處理 mm² 與 cm² 的百倍差。
2. 以 Vu（tf）、bo、d（mm）求 vu（kgf/cm²）：`vu=Vu·100000/(bo·d)`。
3. 舊 D14 題設的根號強度式原為 SI 係數 0.33。若 fc 改 kgf/cm²、bo、d 仍 mm、Vc 改 tf，等價式為 `Vc=1.053788857377494·√fc·bo·d/100000`。不可以只把 fc 數字換算而保留原係數及輸出單位。
4. β1 的材料強度分段與應變判斷先用同一內部標準計算；fy 與 Es 同時換重力應力後，fy/Es 降伏應變維持不變。
5. 扭轉剪流採 T（tf·m）、Ao（mm²）時，`q=T×10^7/(2Ao)` 得 kgf/cm；s 仍為 mm 時，`At=10qs/fy` 才得 mm²。這兩個係數來自 tf·m→kgf·cm、mm²→cm² 及 cm²→mm²，不能省略。
6. T 梁若 T、Cw、Cf 已先用 kgf、力臂仍 mm，`Mn=(Td−Cw·a/2−Cf·hf/2)/10^6` 才得 tf·m；此處分母 10^6 正確，與第一項直接以 As（mm²）及 fy（kgf/cm²）代入的 10^8 不矛盾。前者必須先算 `T=As·fy/100`，混凝土壓力合力也先將受壓面積除以100。
