# 學習工作室 / Learning Lab

五個主題，每科30天：結構學、鋼筋混凝土、鋼結構、耐震設計及結構動力、土壤力學及大地工程。公開部分只含通用教材與網頁程式。

## 試用版功能

- 30天課表、短題、觀念速查與核對答案。
- 計時、暫停、離開分頁自動暫停；重新整理後保持暫停。
- 每課草稿、保留歷次作答、數值核對、錯因與白話解釋。
- 受力圖、剪力／彎矩圖、變形圖三張可編輯圖紙；直線、箭頭、支承、均佈載重、彎矩、文字、自由筆與曲線。
- 拖移、端點調整、剪下／複製／貼上、復原／重做、支承旋轉、底圖與SVG下載；圖解隨JSON備份及歷次作答保存。
- 每課提供解題步驟或作答提示、白話參考及圖解要點；完整數值詳解的覆蓋仍有限。開啟參考會記錄已看答案，不能當作閉卷獨立完成。
- 僅目前瀏覽器儲存；JSON匯出、還原與重複紀錄合併。
- 沒有登入、Firebase、跨裝置自動同步或AI自動批改。

數值核對只是一部分，受力模型與推導仍須教練審閱。此為教學模型，不是實案工程認證。

## 本機檢查

需要Node.js 22或更新版本，無第三方執行期相依。

```sh
npm test
npm run build
```

`site/`是完整靜態網站。教材生成器接收私有教材資料夾參數，只輸出通用課表與題目，不能把學習紀錄或私有文件加入發布目錄。

## 發布

GitHub Pages由`gh-pages`分支根目錄發布；`main`保存程式與測試。只有`site/`可推送至發布分支。

```sh
npm run inject-seed-fields
npm test
npm run build
# 取得使用者同意後：
git subtree push --prefix site origin gh-pages
```

## 紀錄與備份

資料位於本網站origin的localStorage；不同瀏覽器、裝置及網域不會自動共用。請定期匯出JSON。瀏覽器限制、無痕模式或清除瀏覽資料可能令紀錄消失。匯出的個人紀錄不要提交到公開repo或issue。

原始作答與提示次數保留；本版狀態為已提交／待審閱，不宣告完整能力驗收通過。教練可在使用者提供私有JSON後進行回饋。

舊版純文字JSON仍可匯入，沒有圖解欄位時視為未作圖。圖解只保存受限制的向量資料，不接受任意SVG或腳本匯入。備份檔上限20MB，實際瀏覽器儲存額度依環境而異。

開發驗證可用`?sandbox=1`，會顯示功能測試標示並使用獨立的瀏覽器儲存鍵，不修改正式學習紀錄。這仍是本機資料，不是雲端帳號或登入模式。

- `node scripts/backup-records.mjs [JSON檔]`驗證並複製瀏覽器匯出紀錄至本機歷史備份；自動偵測可用備份根目錄，或設定`LEARNING_LAB_BACKUP_ROOT`。同名檔不覆蓋，遠端同步須另行確認。
- 瀏覽器驗證使用獨立測試空間，涵蓋切科、計時、圖解、提交、重新整理、匯出／還原、錯科匯入與手機寬度；功能測試不算學習成果。
