LEARNING LAB · 實體裝置驗證

把備份帶到手機，
再帶回來。

先在 iPhone／Safari 操作，再以另一台平板重做。每台各用自己的測試連結；成功訊息與收據是驗收依據。

這裡是隔離測試。請確認學習頁頂端顯示「功能測試空間」。模擬資料不匯入正式學習空間；既有草稿若衝突，停止並回報，不刪除舊資料。

先從手機開始

選擇目前手上的裝置

① iPhone 測試入口 ② 平板測試入口

請用 Safari 一般分頁開啟，並使用原本連接平台的同一個 Google 帳戶。若平板是 iPad，也用 Safari；其他平板請一併記下系統與瀏覽器。

手機批次：20261014-phone02；平板批次：20261014-tablet02。兩批不能互換。請保留本指南分頁，測試入口會另開分頁。

1．連接 Google，讀回五科並回存
  1. 在對應入口按「連接 Google」，完成裝置上的帳戶選擇。看到「私人驗證空間已連接」後繼續。
  2. 手機：兩份版本已由電腦準備，直接按「B：還原並回存」。
    平板：首次先按「A：寫入兩版」，等完成後再按「B：還原並回存」；這會直接測試平板新增備份，之後由電腦回讀驗收。
  3. 保持分頁開啟，等到「B 還原並回存完成；詳細結果見下方收據。」。此步自動核對五科，並新增第三版。
  4. 先按「下載驗證收據」留一份。畫面若顯示「未通過」，保留訊息並回報，不當作已完成。

本階段通過：五科均有 B-restore-return、pass: true；不能只以登入成功當作備份成功。

2．下載一科，完整還原到學習畫面
  1. 在「核對圖解與匯入」選「結構學」，按「下載已讀回的第二版 JSON」。
  2. 按同一區的「開啟功能測試空間」。新分頁上方必須顯示「功能測試空間」。
  3. 在「備份與還原」點「還原或合併備份」，從檔案選取器挑剛下載、包含目前批次及科目名稱的 JSON。
  4. 應顯示「已合併，共2筆作答。」。若不是 2 筆或出現草稿衝突，先停止並回報完整訊息。

iPhone／iPad 的下載檔可在「檔案」App 的「下載項目」找到；Safari 也有下載項目按鈕。實際儲存位置依您的設定而定。Apple 官方操作說明

請選 JSON 檔，不要把畫面文字複製成另一個檔案。下載名稱通常為 verification-批次-科目.json。

3．查看原稿、圖形與草稿
  • 進入「紀錄與重練」，確認有 D01、D02 兩筆，逐一展開「查看原稿與圖解」。
  • D01 舊圖應保留原受力圖、原剪力／彎矩圖及原變形圖；D02 應看到該科的新版圖紙、箭頭、載重、支承、曲線與「驗證標註」。
  • 展開 D02 的數值題，確認首次數值 -17.25仍在，而且與後續原答／訂正分開列出。
  • 進入「今日練習」，選 D02。確認「尚未提交的驗證草稿」、原圖及約 00:12 計時；先不修改此份原草稿。C 模式的協助依學習階段收合，屬正常行為。
  • 直式、橫式各看一次，確認功能鍵可點、文字可讀、圖形沒有被工具列遮住。這是實機觀察，不由電腦模擬替代。
4．再匯出、逐欄核對，五科都做一次
  1. 回到「備份與還原」，按「匯出完整紀錄 JSON」，確認新檔已下載。
  2. 切回原本的驗證分頁，科目仍選同一科；在「核對從學習平台再匯出的 JSON」選剛匯出的 learning-lab-科目-日期.json。
  3. 必須看到「通過：原始作答、圖解、提示與草稿全部一致。」。保留這個畫面。
  4. 依序改選鋼筋混凝土、鋼結構、耐震設計及結構動力、土壤力學及大地工程，重做第 2～4 步。每次用驗證頁的「開啟功能測試空間」進入正確科目。
  5. 五科完成後，再下載一次「驗證收據」。以最後下載的版本為準，應有五個 platform-export-match 通過項目。

若 Safari 在分頁切換後重新載入驗證頁，請重新連接 Google 並按 B。已存在的相同快照會去重；先前未下載的畫面收據可能已重置，請重做並保存所需核對。

5．觸控繪圖補測（與原稿分開）

先完成並下載第 4 步收據，再以結構學 D03 的空白測試草稿操作。若 D03 已有資料，保留並回報，不清空。

  1. 選「自由筆」畫一條曲線，再畫箭頭、矩形及圓形；確認矩形、圓形有實際寬高。
  2. 試一次復原／重做，再選「捲動／瀏覽」移動畫面。平板若使用觸控筆，記下筆款及是否正常。
  3. 匯出完整 JSON，再交回結構學的核對欄；原 D01、D02 及 D02 草稿仍須通過。
  4. 將新增觸控圖的 JSON 與截圖另外交回教練。本項驗證觸控及本機匯出保全，不宣稱新增筆跡已回存雲端；雲端往返由第 1 步獨立驗證。

完成後交回什麼？

  • 裝置型號、iOS／iPadOS 版本、瀏覽器；平板請確認確實使用另一台裝置。
  • 最後下載的 cloud-verification-對應批次.json 收據，以及一張圖解或核對成功畫面。
  • 若做了觸控補測：附新增筆跡的完整 JSON。遇到問題：附科目、步驟、錯誤原文。

請回到原對話附上檔案。教練再從電腦回讀第三版、核對完整資料與正式歷史，才完成該裝置驗收。尚未收到實機證據前，狀態維持「待實機操作」。

這份指南不收集裝置資訊、不上傳作答，也不新增 Google 權限。登入與雲端寫入只在您點入的驗證頁進行。
